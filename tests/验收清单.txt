GalAutoTL 验收清单（自动化测不到的部分）
========================================

自动化测试能锁「已知逻辑复辟」。下面这些仍需人工/半自动，发现新坑后应补进 tests/。

1) 图片 UI
   - 标题「开始/读档」等若是 button_*.png/tlg，机翻改不了
   - 做法：界面「图片UI清单」→ GalAutoTL_image_ui.txt → GARbro 解图改字 → 覆盖
   - 自动化：只能扫脚本 graphic=/storage= 引用，不能验画面

2) 译质（语义对不对）
   - 测试可用假 AI 输出验「毒译/花屏会被丢掉」
   - 不能保证「莫妮卡」一定比「莫尼卡」好
   - 做法：对照表 GalAutoTL_review.txt 抽检 + 通读

3) 整游戏漏翻
   - 迷你 e2e 只覆盖样例树，不是全封包
   - 做法：开游戏走标题/存读/设置/一章剧情
   - 漏句：GalAutoTL_remain.txt（已分类）→ 界面「仅译漏句」再跑一轮

4) 实机稳定性
   - 开机黑屏、中途崩、字体方块：要真机 + Locale Emulator
   - Kirikiri：确认没有错误的根目录 Config.tjs；用 patch2 不是 patch.xp3
   - LCSE：用中文启动 bat，勿日语 LE（按该管线说明）

5) 新引擎/变种
   - 新格式第一次漏：测不到
   - 修好后：把最小复现丢进 tests/，防止再犯

建议节奏
--------
改核心代码 → 运行测试.bat
发一版给自己玩 → 按本清单点一遍
发现新坏点 → 修代码 + 加一条 pytest
